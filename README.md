# 데이터로 바라본 한국: 인구·저출산·고령화

서울대 행정대학원 고길곤

이 저장소는 한국의 인구 변화, 저출산, 고령화 정책을 데이터로 분석한 공개 웹북입니다. 공개본은 읽기 전용이며, 각 장과 절의 상단에 있는 **이 절에 의견 남기기** 버튼을 통해 GitHub Issues에 의견을 남길 수 있습니다.

## 보기

GitHub Pages가 활성화되면 다음 주소에서 볼 수 있습니다.

https://kilkon.github.io/fertility/

로컬에서는 `index.html`을 브라우저로 열면 됩니다.

## 구성

- `index.html`: 표지와 목차
- `chapters/`: 장별 HTML
- `sections/`: 절별 HTML
- `manuscripts/`: 책 원고 마크다운
- `data/derived/`: 그림별 다운로드 CSV
- `book_chart_data.js`: 차트 렌더링용 데이터
- `book_pages.js`, `site.css`, `_book_pages.css`: 웹북 UI와 시각화 코드

## 의견 남기기

본문 수정은 공개 페이지에서 허용하지 않습니다. 대신 각 절의 의견 버튼을 누르면 해당 절 제목과 파일명이 자동으로 들어간 GitHub Issue 작성 화면이 열립니다. 자료 오류, 해석 보완, 추가 질문을 남겨주시면 이후 원고 개정에 반영할 수 있습니다.
